# 設計と制約

- デバイスクラスは通信非依存です。公開メソッドは動的ディスパッチで呼び出します。
- 一対多配信はMQTT標準Pub/Subで行い、結果集約を必須としません。
- A（一つのサーバーに多数のクライアント）は、各クライアント固有の応答Topicで成立します。
- B（一つのクライアントから多数のサーバー）は、複数サーバーが同一Topicを購読する形で成立します。ただし現状の `DeviceServer` は個別RPC Topicのみ購読するため、Bをデバイスクラスのメソッド呼び出しとして透過的に行う機能は未実装です。
- property、非同期メソッド、バイナリ型、独自クラスの直列化、デバイス専用pyi、再送時の重複実行抑止は未実装です。
- QoS 1はコマンドのexactly-once実行を保証しません。安全系停止指令には使用しないでください。
- この版のAPIは既存 `grpc_frame`、`ese774_frame` のソース互換性を検証していません。
